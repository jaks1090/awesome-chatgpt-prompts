Welcome! This project started as a curated set of practical prompts and has grown into a resource hub for prompt writers, AI teams, and curious builders.

## What this site is for

- Finding high-quality starter prompts quickly.
- Learning prompt writing patterns that are reusable across tasks.
- Experimenting with analytics and mapping interfaces for future prompt discovery tools.
